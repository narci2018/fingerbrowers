🤖 Model Context Protocol (MCP) 原生集成中心

原生兼容 Donut 的 AI Agent 调度设计。无需复杂代码，AI 智能体即可无缝掌控真人指纹环境。

1. Claude Desktop / Antigravity 配置指南

将以下 JSON 代码加入到您的 AI 客户端配置文件（如 claude_desktop_config.json）：

{ "mcpServers": { "phantom-fingerprint-browser": { "command": "python", "args": ["c:/Tools2/fingerbrowers/mcp_server/server.py"] } } }
